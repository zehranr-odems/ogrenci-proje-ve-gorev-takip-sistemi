# Öğrenci Proje ve Görev Takip Sistemi

Bu proje, öğrencilerin görevlerini, projelerini ve önemli tarihlerini daha düzenli şekilde takip edebilmesi amacıyla geliştirilmiş web tabanlı bir yönetim sistemidir.

Sistem PHP, MySQL, HTML, CSS ve JavaScript teknolojileri kullanılarak geliştirilmiştir. Kullanıcılar görev ve proje ekleyebilir, güncelleyebilir, silebilir ve ilerleme durumlarını takip edebilir.
